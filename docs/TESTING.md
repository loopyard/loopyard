# Testing

## Philosophy

**Every feature needs tests.** Write failing tests first, then implement. This prevents regressions that waste hours of debugging.

We've been burned multiple times by features that "worked" but had no tests:
- Message URLs showed "not found" because broadcasts lacked IDs — no test caught it
- Copy link buttons broke repeatedly — no test verified the href
- ETS race conditions in exec_stream — no test verified message persistence

The cost of writing a test is 5 minutes. The cost of debugging a regression in a live session is an hour of frustration.

## Running tests

```bash
mix test                    # Run all tests (excludes :docker, :worktree)
mix test --trace            # Verbose output
mix test --include docker   # Include Docker integration tests
mix test path/to/test.exs   # Run specific file
mix test path/to/test.exs:42  # Run specific test at line 42
```

## Test tags

| Tag | Meaning | When to use |
|-----|---------|-------------|
| `@tag :docker` | Requires Docker daemon | Container operations, compose lifecycle |
| `@tag :worktree` | Creates git worktrees | Branch operations that create worktrees |

Excluded by default in `test_helper.exs`. Include with `--include docker`.

## Test helpers

```elixir
# Start a workspace supervisor subtree (required before starting agents)
BoomLooper.TestHelpers.ensure_workspace(path)

# Start an agent under the correct workspace supervisor
BoomLooper.TestHelpers.start_agent(
  id: "test-#{:rand.uniform(100_000)}",
  name: "Test Agent",
  working_dir: tmp_dir,
  bind_mount: tmp_dir,
  started_by: "test"
)
```

Always use random IDs to avoid test interference. Always clean up in `on_exit`:

```elixir
on_exit(fn ->
  try do
    BoomLooper.ChatAgent.stop_agent(id)
  catch
    :exit, _ -> :ok
  end
  Process.sleep(50)
end)
```

## Test contracts

These are the invariants that tests must verify. If you break one of these, things cascade.

### Message IDs

Every message must have a unique, non-nil `:id`. This is what makes message URLs work.

```elixir
# Every message has an ID
for msg <- state.messages do
  assert msg[:id] != nil
end

# IDs are unique
ids = Enum.map(state.messages, & &1[:id])
assert ids == Enum.uniq(ids)

# get_message can find by ID
found = ChatAgent.get_message(agent_id, msg.id)
assert found != nil
assert found.id == msg.id
```

Test file: `test/boom_looper/chat_agent_test.exs`, `test/boom_looper_web/live/message_live_test.exs`

### Message URLs

URLs generated by `OutputController.msg_url/2` must load in MessageLive and show content:

```elixir
url = BoomLooperWeb.OutputController.msg_url(agent_id, msg.id)
{:ok, _view, html} = live(conn, url)
assert html =~ msg.content
refute html =~ "Message not found"
```

Test file: `test/boom_looper_web/live/message_live_test.exs`

### Agent lifecycle

Agents transition through states: `:booting` → `:idle` → `:thinking` → `:idle` → `:stopped` → `:destroying`.

```elixir
# Booting agent shows booting screen
ChatAgent.register_booting(id, "Name", path)
{:ok, _view, html} = live(conn, chat_path)
assert html =~ "Starting agent"

# Running agent shows chat
{:ok, _pid} = TestHelpers.start_agent(opts)
{:ok, _view, html} = live(conn, chat_path)
assert html =~ "Send"

# Unknown agent redirects with error
assert {:error, {:live_redirect, _}} = live(conn, bad_chat_path)
```

Test file: `test/boom_looper_web/live/chat_live_test.exs`

### Service status broadcasts

ServiceManager broadcasts must reach LiveViews and update the sidebar:

```elixir
ServiceManager.subscribe()
ServiceManager.start_services(tmp_dir)
assert_receive {:services_updated, ^tmp_dir, statuses}, 2000
assert is_list(statuses)
```

Test file: `test/boom_looper/workspace/service_manager_test.exs`

### Container reconnect

ServiceManager reconnects to existing compose containers on restart:

```elixir
# Reconnect restores state
assert :ok = GenServer.call(pid, {:reconnect, ws})
assert {:ok, statuses} = ServiceManager.service_status(tmp_dir)
assert length(statuses) == expected_count

# Terminate does not call compose down
GenServer.stop(pid, :normal)
refute Process.alive?(pid)
# Containers still running (verified separately)
```

Test file: `test/boom_looper/workspace/service_manager_test.exs`

### MCP tool structure

Each MCP tool server must be valid and have expected tools:

```elixir
assert ClaudeCode.MCP.Server.sdk_server?(Container)
tool_names = Container.__tool_server__().tools |> Enum.map(& &1.__tool_name__())
assert "exec" in tool_names
```

Test file: `test/boom_looper/tools/container_test.exs`

## When to write tests

- **New feature**: Write tests BEFORE implementation. Red/green cycle.
- **Bug fix**: Write a failing test that reproduces the bug, then fix it.
- **Refactor**: Existing tests must still pass. Add tests if coverage is weak.
- **New MCP tool**: Test that the tool exists, has correct name, handles error cases.
- **New LiveView route**: Test that it renders, handles PubSub updates, and navigates correctly.
- **State change**: Test that PubSub broadcasts fire and LiveViews update.
