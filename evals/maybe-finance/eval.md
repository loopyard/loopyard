Rails 7 personal finance app. Tests the setup agent's ability to configure a Ruby on Rails dev environment with PostgreSQL.

Expects: Dockerfile with Ruby base image, postgres service, dev command running `bin/dev` or `rails server` bound to 0.0.0.0, database creation and migration via post-rebuild exec.
