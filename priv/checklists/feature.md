# Feature Development

Implement a new feature following best practices.

- [ ] Understand the requirements and acceptance criteria
- [ ] Create a feature branch
- [ ] Write failing tests for the feature
- [ ] Implement the feature to make tests pass
- [ ] Verify all tests pass (not just new ones)
- [ ] Commit changes with descriptive message
- [ ] Push branch and create pull request

## Notes
- Follow the project's existing code style and patterns
- Keep commits atomic and focused
- Use `get_secret` for any tokens needed (GitHub, deploy, etc.)
